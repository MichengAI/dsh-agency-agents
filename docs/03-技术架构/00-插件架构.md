# 插件架构

## 数据流

`assets\agency-agents` 或外部 `root` → 递归扫描 Markdown frontmatter → 智能体目录 → `list_experts` 路由 → `summon_expert` → DSH 一次性子代理 → 主会话汇总。

## 组件职责

- `src\index.ts`：解析 frontmatter、加载目录、注册工具和系统提示。
- `src\i18n.ts`：宿主侧中英文词条，以及分区/专家名的语言切换。
- `src\names.ts`：中英文分区名与中文专家名。
- `src\client\locales.ts`：设置页、按钮、`@` 菜单的客户端词条。
- `cordis.patch.yml`：通过 DSH bundle 把插件挂载进 profile。
- `scripts\verify.mjs`：校验构建入口、发布文件、bundle patch 和许可证资产。
- `assets\agency-agents`：上游 persona 快照；仅其中的合法 frontmatter Markdown 会进入目录。

## 边界

此插件不保存团队状态、不维持成员会话、不处理任务依赖。复杂的持久化多代理协作应由专用团队编排插件承担。
