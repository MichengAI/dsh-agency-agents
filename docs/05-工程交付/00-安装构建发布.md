# 安装、构建与发布

## 安装

使用 `dsh plugin --profile <profile> add <插件目录或包名>` 安装；bundle patch 会挂载 `agency-agents`。安装后使用 `dsh --profile <profile> --dump-config` 确认组合结果。

## 验证

- `pnpm build`：先做 TypeScript 类型检查，再构建 ESM 和声明文件。
- `pnpm test`：验证 frontmatter、递归扫描、外部 root 错误和包内默认资产。
- `pnpm verify`：验证发布清单、DSH bundle、构建入口和许可证资产。
- 真实运行：使用隔离 profile 召唤一个专家，确认 provider、persona 和工具过滤均生效。

## 发布

`prepublishOnly` 会依次运行构建、测试和发布验证。发布前检查根目录 Apache `LICENSE`、`NOTICE` 和 `assets\agency-agents\LICENSE` 都在包内。
