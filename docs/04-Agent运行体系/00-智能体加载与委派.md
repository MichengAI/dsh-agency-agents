# 智能体加载与委派

## 来源与快照

内置智能体来自 `https://github.com/msitarzewski/agency-agents`。资产根目录保留上游 MIT 许可证，插件根目录的 Apache-2.0 不覆盖该上游授权。

默认加载 17 个标准分区，并将 `integrations\mcp-memory\backend-architect-with-memory.md` 归入 `engineering`。加载器递归扫描分区子目录，因此游戏开发的 Unity、Unreal、Godot、Blender 和 Roblox Studio 智能体均可发现。

## 路由协议

1. 主会话需要确定 slug 时先调用 `list_experts`；无筛选调用仅返回分区和数量。
2. 主会话调用 `summon_expert` 时提供完整、自包含的任务。
3. 插件校验 provider 支持 persona 与工具过滤；智能体子代理不能调用 `summon_expert` 或 `list_experts`。
4. 如配置正整数 `maxDepth`，插件额外校验 provider 支持深度限制，并把该绝对上限传给子代理。
5. 子代理完成后，主会话接收文本结果并负责最终回复。
