# 技术架构基线

更新时间：2026-08-15 16:50（Asia/Shanghai）

- 运行时：Node.js ESM、TypeScript 严格模式、DSH/Cordis 插件机制。
- 专家资产：`assets\agency-agents` 是默认根目录；外部 `root` 仅为覆盖配置。
- 委派：`summon_expert` 只创建一次性子代理，要求 provider 支持 persona 与工具过滤。
- 安全：专家子代理拒绝调用 `summon_expert`，防止同一插件的递归委派。
- 发布：包必须包含 `lib`、专家资产、`cordis.patch.yml`、Apache `LICENSE` 和 `NOTICE`。
