# 技术架构基线

更新时间：2026-08-15 20:08（Asia/Shanghai）

- 运行时：Node.js ESM、TypeScript 严格模式、DSH/Cordis 插件机制。
- 智能体资产：`assets\agency-agents` 是默认根目录；显式 `root` 优先，其次读取 `AGENCY_AGENTS_ROOT`。
- 委派：`summon_expert` 只创建一次性子代理，要求 provider 支持 persona 与工具过滤。
- 安全：智能体子代理拒绝调用 `summon_expert` 与 `list_experts`，防止同一插件的递归委派和无效花名册浏览。
- 深度：`maxDepth` 为可选正整数绝对上限；未配置时不改变宿主的既有深度策略。
- 发布：包必须包含 `lib`、智能体资产、`cordis.patch.yml`、Apache `LICENSE` 和 `NOTICE`。
