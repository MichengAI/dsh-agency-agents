# 技术架构基线

更新时间：2026-08-17 03:00（Asia/Shanghai）

- 运行时：Node.js ESM、TypeScript 严格模式、DSH/Cordis 插件机制。
- 智能体资产：`assets\agency-agents` 是默认根目录；显式 `root` 优先，其次读取 `AGENCY_AGENTS_ROOT`。
- 委派：`summon_expert` / `summon_experts` 只创建一次性子代理，要求 provider 支持 persona 与工具过滤。
- 安全：智能体子代理拒绝调用 `summon_expert`、`summon_experts` 与 `list_experts`，防止递归委派和无效花名册浏览。
- 深度：`maxDepth` 为可选正整数绝对上限；未配置时不改变宿主的既有深度策略。
- 启停与持久化：通过 `@deepseek-ai/dsh-settings` 的 settings namespace（`agency-agents`，schema `{ enabled: string[] }`）在宿主侧持久化；**白名单语义，默认全停用**，用户在设置「专家」标签页启用。宿主工具按「已启用」过滤。
- 客户端取数：启用状态不经过 `api.settings`（那是 Host 自有配置面，`WEB_SETTINGS_NAMESPACES` 白名单对第三方插件硬编码封死），改走插件自有的 **Typert Remote** 通道 —— 宿主 `AgencyAgentsRemote extends TypertRemoteService`（`@Remote getEnabled/setEnabled`）由 gateway SRC 自动发现，客户端 `$mount(TYPERT_REMOTE)` 后经 `ctx.remote.agencyAgents` 读写（`src/client/remote.ts` 手写 strict 贡献）。第三方安装无需修改或重编 DSH 源码。
- 客户端：client bundle（`lib/client.js`，`window.__ModuleLoader__.load` 格式）提供 composer「专家」按钮 + 弹窗、设置「专家」标签页、@ 菜单；静态花名册与中英文名打包进 client（`src/client/roster.ts`、`src/names.ts`）。界面词条走 `agency` 命名空间；专家名/简介/排序跟随 `locale` 的 `zh`/`en`。
- 宿主文案：`list_experts` 的名单、分区标题和用户可见错误读取 settings `locale.preference`（仅显式 `en` 走英文，其余回退 `zh`）。分区筛选同时认 key、中文名和英文名。
- 发布：包必须包含 `lib`（含 `client.js`）、智能体资产、`cordis.patch.yml`、Apache `LICENSE` 和 `NOTICE`。

## 与早期临时动态插件（agency-1）的差异

开发期曾用动态 Cordis 插件（`agency-1`）快速验证交互，正式包已改为 DSH 正规机制，二者**界面一致、实现不同**，状态也不互通：

| 维度 | 临时动态插件 agency-1 | 正式包 @michengai/dsh-agency-agents |
| --- | --- | --- |
| 资产来源 | 硬编码 `D:/Repository/agency-agents` | 随包 `assets/agency-agents/`（`root`/环境变量可覆盖） |
| 文件读取 | `ctx.get('fs')` 服务 | `node:fs/promises` |
| 启停持久化 | 手写 JSON（`~/.dsh/agency-agents-state.json`） | settings namespace（`{ enabled: [] }`） |
| 客户端取数 | 私有 RPC `host.call('experts:*')` | 插件 Typert Remote（`ctx.remote.agencyAgents`） |
| 花名册 | 宿主按需下发 | 静态打包进 client |
| deny 列表 | `summon_expert`/`summon_experts` | 额外多禁 `list_experts` |
| maxDepth | 无 | 支持可配置上限 + `depthLimit` 校验 |
| systemPrompt | 静态、所有会话可见 | 仅父会话可见（子代理读到空） |

该动态插件仅用于开发期验证，未固化、进程重启即失；正式包是唯一随包发布、自包含的实现。
