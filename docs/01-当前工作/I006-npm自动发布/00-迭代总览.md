## 验收标准

- 推送与 `package.json` 版本一致的 `v*` 标签后，工作流成功执行 `pnpm prepublishOnly` 与 `npm publish`。
- npm `latest` 标签指向新版本。
- 工作流未使用 `NPM_TOKEN` 或令牌式 registry 配置。
