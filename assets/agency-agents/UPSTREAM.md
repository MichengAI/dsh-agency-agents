# 上游来源

本目录包含 [The Agency](https://github.com/msitarzewski/agency-agents) 的智能体 persona 快照，供 `@deepseek-ai/dsh-agency-agents` 零配置运行。

- 来源：`https://github.com/msitarzewski/agency-agents`
- 授权边界：本目录的上游智能体 persona 继续采用 MIT，完整文本见同目录 `LICENSE`；插件源码、构建脚本和项目文档采用根目录的 Apache-2.0 许可证。
- 更新方式：同步上游的智能体目录和许可证后，执行本包的 `pnpm test`、`pnpm build`、`pnpm verify`。
